# Presentation Style Rules

These rules apply to all content in `docs/presentation/presentation.md`, including slide text and `<!-- speaker script -->` comment blocks.

- **No em dashes or en dashes**: Use a hyphen `-` instead of `—` or `–` everywhere, including inside comment blocks
- **No icons or emojis**: Do not use emoji characters or icon fonts anywhere in the file
- **Arrows**: Use `->` not `→` or any Unicode arrow character, including inside comment blocks
